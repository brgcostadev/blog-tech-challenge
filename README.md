# Blog Tech Challenge API

API REST para gerenciamento de posts, desenvolvida para o Tech Challenge da Pós Tech Full Stack.

## Tecnologias utilizadas

- Node.js
- Express
- PostgreSQL
- Docker
- Swagger
- Dotenv
- Nodemon

## Funcionalidades

- Listar posts
- Buscar post por ID
- Criar post
- Atualizar post
- Excluir post
- Validação de campos obrigatórios
- Documentação com Swagger
